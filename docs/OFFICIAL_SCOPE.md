# 再現対象の範囲

監査報告書 `MARS_AUDIT_REPORT_2026-09-08.md` §4.1 が求めた対応表。
「何を公式どおり再現しているつもりか」を宣言し、**公式と一致していない箇所を既知の相違として明示する**ためのもの。

判定は3種類。

- **公式準拠** — 一次資料と照合し、テストで期待値を固定したもの。
- **既知の相違** — 実装はあるが公式と異なることが分かっているもの。**独自ルールとして扱う。**
- **未実装** — 選択経路がないもの。既存機能の故障とは区別する。

### アマゾニス平原（R2、修正済み）

一次実装（`src/server/boards/AmazonisBoard.ts` ほか）と機械的に照合して修正した。

**盤面**：全4マップの builder 呼び出しを正規化して差分を取ったところ、
ヘラス・エリシウム・ユートピアは完全一致、**アマゾニスだけ y=4 行の末尾4マスが誤り**だった。

```
上流: .land(HEAT,HEAT).volcanic(PLANT,PLANT).land().land(TITANIUM,TITANIUM)
旧  : .land(HEAT,HEAT).land()               .land(PLANT).land(PLANT)
```

火山マス1つが抜け、ボーナスが2マス分違っていた。`scripts/generate-boards.mjs` を直して再生成済み。

**称号・表彰**：ユートピアの配列を借用していたのを、一次実装から転記した固有10種に置き換えた。

| 称号 | 条件 | 表彰 | 条件 |
|---|---|---|---|
| Colonizer 入植者 | 植民地4つ | Curator 学芸員 | 同一種タグ最多（イベント除く） |
| Forester 森林管理者 | 植物生産量4 | A. Engineer 技師 | 自分の生産量を変えるカード最多 |
| **Minimalist ミニマリスト** | **手札2枚以下** | Promoter 興行主 | イベントカード最多 |
| Terran 地球人 | 地球タグ6 | Tourist 旅行者 | 自タイルに隣接する空きマス最多 |
| Tropicalist 熱帯育ち | 赤道付近3列にタイル3枚 | A. Zoologist 動物学者 | 動物・微生物資源最多 |

Minimalist は**下回ることで獲得する初の称号**で、`getMilestoneStatus` は
`score >= threshold` を全称号に適用していた。`atMost` フラグを追加して比較方向を分けた。

**終局条件とトラック**：監査報告は「長いパラメータトラック」「追加海洋タイル」を挙げていたが、
**一次実装にはアマゾニス固有の終局条件もトラックも存在しない**
（`AMAZONIS` の参照は `GameSetup.ts` と `MilestoneAwardSelector.ts` の2箇所のみ）。
共通の `isGameOverCheck` のままで正しい。物理製品の同梱物と、
再現対象である一次実装の実装範囲は別の話として扱う。

### プレリュードの箱（R7、修正済み）

## 完了判定

「完全再現」の完了は、カード枚数や成功テスト数ではなく、
**この表に未対応・既知の相違が残っていないこと**で判定する。
上の表に「既知の相違」「未実装」「範囲未確定」が1つでもある限り、完全再現とは呼ばない。
