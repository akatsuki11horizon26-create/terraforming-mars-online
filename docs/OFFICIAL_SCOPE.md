# 再現対象の範囲

監査報告書 `MARS_AUDIT_REPORT_2026-09-08.md` §4.1 が求めた対応表。
「何を公式どおり再現しているつもりか」を宣言し、**公式と一致していない箇所を既知の相違として明示する**ためのもの。

判定は4種類。

- **公式準拠** — 一次資料と照合し、テストで期待値を固定したもの。
- **既知の相違** — 実装はあるが公式と異なることが分かっているもの。**独自ルールとして扱う。**
- **未実装** — 選択経路がないもの。既存機能の故障とは区別する。
- **未検証** — 一次資料との突合が足りず、公式準拠とはまだ言えないもの。

### アマゾニス平原（印刷盤面の全91マスを照合済み）

一次実装（`src/server/boards/AmazonisBoard.ts` ほか）と機械的に照合した旧61マス版は、公式製品とは異なっていた。[公式同梱説明書](https://fryxgames.se/wp-content/uploads/2024/09/TM_AV_WRAP_ENG.pdf)にある拡張盤面・長いパラメータに合わせ、現在は91マス、気温14℃・酸素18%・海洋11枚の終局条件、任意の金星33%トラックを実装している。ソロの世代上限も1世代延長する。[印刷盤面の製品写真](https://www.svet-her.cz/spolecenske-hry/mars-teraformace-amazonis-vastitas)と[別角度の写真](https://www.rebel.pl/gry-planszowe/terraformacja-marsa-amazonis-i-vastitas-2020175.html)をもとに、海洋専用マス・個別ボーナス・火山を全91マス照合し、行単位の回帰テストで固定した。

**旧61マス版の照合履歴**：全4マップの builder 呼び出しを正規化して差分を取ったところ、
ヘラス・エリシウム・ユートピアは完全一致、**アマゾニスだけ y=4 行の末尾4マスが誤り**だった。

```
上流: .land(HEAT,HEAT).volcanic(PLANT,PLANT).land().land(TITANIUM,TITANIUM)
旧  : .land(HEAT,HEAT).land()               .land(PLANT).land(PLANT)
```

火山マス1つが抜け、ボーナスが2マス分違っていた。`scripts/generate-boards.mjs` を直して再生成済み。

**称号・表彰**：以前は一次実装の固有10種を採用していたが、公式製品の印字内容とは異なっていた。[公式同梱説明書](https://fryxgames.se/wp-content/uploads/2024/09/TM_AV_WRAP_ENG.pdf)に合わせ、現在の新規試合では以下の10種を使用する。旧セーブに出資済みの旧表彰は、得点計算を維持するため登録だけ残す。

| 称号 | 条件 | 表彰 | 条件 |
|---|---|---|---|
| Terran 地球人 | 地球タグ5 | Collector 収集家 | 資源の種類最多（プレイヤーボードとカード上） |
| Landshaper 造地家 | 緑地・特殊・都市タイルを各1枚 | Innovator 革新者 | プレイしたカード最多（イベント含む） |
| Merchant 商人 | 標準資源6種を各3個 | Constructor 建設家 | 植民地と都市タイルの合計最多 |
| Sponsor 後援者 | コスト20 MC以上の場のカード3枚 | Manufacturer 製造家 | 建材と熱の生産量合計最多 |
| Lobbyist ロビイスト | 代表者7人全員が議会にいる | Physicist 物理学者 | 科学と宇宙タグ合計最多 |

旧版の Minimalist は登録済みでも新規試合の称号一覧には出ず、コマンド経由でも新たに獲得できない。

**終局条件とトラック**：一次実装にはアマゾニス固有の終局条件もトラックも存在しなかった。現在は共通トラックの上限をこの盤面だけ延長し、カード効果・海洋配置・ソロ勝利判定にも適用している（`tests/alternate-boards.test.mjs`）。

### ヴァスティタス・ボレアリスの `TEMPERATURE` 配置ボーナス

このマスにタイルを置くと、支払える場合は**4 MCを払って気温+1段階**上がる。
[公式同梱説明書](https://fryxgames.se/wp-content/uploads/2024/09/TM_AV_WRAP_ENG.pdf)で金額と必須効果を確認した。以前の3 MC・辞退可能という実装を修正し、資金不足・気温上限・複合ボーナス・配置後の継続処理・保存再読込を検証している。

称号・表彰も旧一次実装の10種ではなく、同じ公式説明書にある Agronomist、Engineer、Spacefarer、Geologist、Farmer と Traveller、Landscaper、Highlander、Promoter、Blacksmith に変更した。旧セーブに出資済みの旧表彰は得点計算を維持する。

**盤面**：[公式製品の盤面写真](https://thirstymeeples.co.uk/products/terraforming-mars-amazonis-vastitas)と[別版の製品写真](https://www.svet-her.cz/spolecenske-hry/mars-teraformace-amazonis-vastitas)を用いて、全61マスの土地・海洋指定と配置ボーナスを行ごとに照合した。Viking 1・2 の代表ボーナス、4火山の位置・名称、北極の気温ボーナスも照合済み。全マスの期待値は `tests/alternate-boards.test.mjs` に固定した。

### プレリュードの箱（R7、修正済み）

`enabledExpansions({ prelude: true })` は Prelude と Prelude 2 の両方を有効化していた。
現在は独立した設定で、旧セーブ・旧ルームのように `prelude` だけを送ってきた
呼び出し元は従来どおり両方を受け取る（`options.prelude2 ?? options.prelude`）。

### 植民地の報酬

エンケラドゥス・ミランダ・タイタンのカード上資源は、該当資源を保持できる
カードから配置先を選ぶ。候補が1枚だけなら自動で置く。
エウロパ入植時の海洋は、合法なマスから配置先を選ぶ。
プルートの入植者ボーナスは、複数の入植者がいる場合も各人にカードを1枚配り、
持ち主ごとの選択待ちで1枚を捨てる。
デイモスは[一次実装のコミュニティ植民地一覧](https://github.com/terraforming-mars/terraforming-mars/wiki/Community-Colonies)で
Ares必須と明記されるタイルで、[公式Coloniesルール](https://fryxgames.se/wp-content/uploads/2023/07/TM_COLONIES_ENG_RULESi.pdf)の
11枚には含まれない。新規試合の山札と未使用タイル群から除外した。
旧セーブは破壊しないため、既に場にあるデイモスは残るが、その危険地形配置・
侵食・危険地形数に応じたMC獲得は未対応。

### 公式Automaに着手しない理由

一次実装の Automa（MarsBot）は `src/server/automa/` に8ファイル・約720行あり、
**専用の盤面データ・ボーナスデッキ・企業タイプ・タイル配置器**を持つ独立したサブシステム。
既存の3難易度ボットを改造して寄せられるものではない。

これは監査で見つかった**不具合ではなく、未着手の別プロジェクト**である。
現在の3難易度ボットを「公式Automa」と呼ばないこと、
そして呼んでいないことがこの表の役割で、それは満たしている。

着手するなら、専用ルール・データ・得点計算を別管理にする
（監査報告 §4.1 の指摘どおり）。既存ボットの置き換えではなく、追加のモードになる。

## 完了判定

2026-10-06 の再確認では、上流実装との一致だけで公式準拠とした標準ゲームの判定に誤りが見つかった。[公式ルールブックの7・13ページ](https://cdn.1j1ju.com/medias/13/3f/fb-terraforming-mars-rule.pdf)を根拠に、企業の時代のカード除外、初期生産の加算、ソロの設定を修正した。`tests/official-content.test.mjs` で全配布プール、企業を選ぶ実コマンド、保存・再読込を検証する。非公式ボードは追加していない。

上記の既存の「公式準拠」は過去の照合範囲の記録であり、今回すべてのカードと組合せを公式資料から再監査したことを意味しない。上流のコミュニティ実装は比較資料であり、公式ルールの代わりにはしない。

「完全再現」の完了は、カード枚数や成功テスト数ではなく、
**この表に未対応・既知の相違が残っていないこと**で判定する。
上の表に「既知の相違」「未実装」「未検証」「範囲未確定」が1つでもある限り、完全再現とは呼ばない。
