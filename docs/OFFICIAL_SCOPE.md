# 再現対象の範囲

監査報告書 `MARS_AUDIT_REPORT_2026-09-08.md` §4.1 が求めた対応表。
「何を公式どおり再現しているつもりか」を宣言し、**公式と一致していない箇所を既知の相違として明示する**ためのもの。

判定は3種類。

- **公式準拠** — 一次資料と照合し、テストで期待値を固定したもの。
- **既知の相違** — 実装はあるが公式と異なることが分かっているもの。**独自ルールとして扱う。**
- **未実装** — 選択経路がないもの。既存機能の故障とは区別する。

### アマゾニス平原の既知の相違（R2）

公式 *Amazonis Planitia* は以下を持つが、**現実装はいずれも再現していない**。

- 広い盤面（現実装は他マップと同じ9行61マス。`scripts/generate-boards.mjs` が全マップを61マスで生成する）
- 固有の称号 Terran / Landshaper / Merchant / Sponsor / Lobbyist
- 固有の表彰（Collector ほか）
- 長いパラメータトラックと閾値ボーナス
- 追加海洋タイル、専用標準プロジェクト、任意の長い金星トラック
- 終局条件（`app/game-logic.js` の `isGameOverCheck` は気温+8℃・酸素14%・海洋9枚の共通判定で、マップ別の引数を持たない）

現在の盤面データの出典は不明である。公式 Amazonis と一致する確証がないため、
**公式再現とは主張しない。** 称号・表彰はユートピアの配列を借用しており、
これは `app/board-milestones.js` に明示してある。

修正するには公式盤面全マスの座標・ボーナス、トラック上限、称号・表彰の
評価値を一次資料から転記する必要がある。今回の監査ではその転記を行っていない。

### プレリュードの箱（R7、修正済み）

`enabledExpansions({ prelude: true })` は Prelude と Prelude 2 の両方を有効化していた。

## 完了判定

「完全再現」の完了は、カード枚数や成功テスト数ではなく、
**この表に未対応・既知の相違が残っていないこと**で判定する。
上の表に「既知の相違」「未実装」「範囲未確定」が1つでもある限り、完全再現とは呼ばない。
