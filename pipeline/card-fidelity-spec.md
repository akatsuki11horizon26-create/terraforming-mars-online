# 原作カード効果実装仕様

## 対象

- 現在のソロゲームを維持する。
- 対象拡張は基本セットとPrelude 1のみとする。Venus Next、Colonies、Turmoil、Prelude 2、プロモは含めない。
- 現在の20枚の仮カードを、基本セットの実在カード20枚へ置き換える。
- 企業は基本セット13枚（Beginner Corporationを含む）とPreludeの追加5枚を選択候補にする。
- PreludeカードはPrelude 1の35枚を候補にする。
- カード名、コスト、タグ、基本条件、VP、初期資源、生産、即時効果、反復効果は公開されている原作資料とオープンソース実装を照合する。

## セットアップ

- 企業2枚から1枚を選ぶ。
- 初期プロジェクト10枚は1枚3 MCで購入する。
- Prelude 4枚から2枚を選ぶ。Prelude自体の購入コストは0で、企業と初期カードの確定後に選択順で解決する。カード内の任意支払いは効果として処理する。
- 企業の初期MC、資源、生産、タグを状態へ反映する。
- 企業の「最初のアクション」効果を最初のアクション前に解決する。

## 効果エンジン

- 効果はカードIDに依存する分岐ではなく、共通操作の配列として定義する。
- 共通操作はMC、資源、生産、TR、気温、酸素、海洋、カードドロー、カード破棄、タイル配置、タグ条件、カードコスト割引、企業の反復効果を含む。
- タイル配置やカード選択が必要な効果は、既存の配置モードまたは選択UIへ接続する。
- 実装できないカードを架空の効果で代替しない。未対応カードは候補に入れない。
- 表示文は原文の長文転載ではなく、日本語の短い機械的要約にする。

## UI

- セットアップに企業選択とPrelude選択のパネルを追加する。
- 選択中の企業・Preludeのタグ、初期値、効果を表示する。
- 手札・研究カード・プレイ済みカードに、原作のカード種別と短い効果要約を表示する。
- Prelude解決後にのみアクションフェーズを開始する。

## 互換性

- 既存の古いlocalStorage状態は企業・Prelude未選択として破棄し、新しい初期状態へ移行する。
- 現在の標準プロジェクト、14世代ソロ、最終緑化、静的ビルドを壊さない。

## 検証

- 企業18枚、Prelude35枚、プロジェクト20枚の件数をテストする。
- 代表的な企業、Prelude、プロジェクトについて初期値・条件・効果をテストする。
- `npm test`、`npm run lint`、`npm run build` を通す。
