# カード忠実度評価基準

1. PASS: 企業18枚、Prelude35枚、プロジェクト20枚の実在カードが登録され、架空カードが残っていない。
2. PASS: 企業とPreludeをセットアップで選択でき、初期値・タグ・効果が状態に反映される。
3. PASS: 代表的な即時効果、生産効果、パラメータ効果、カードドロー、タイル配置、反復効果がカードID分岐ではなく共通操作で処理される。
4. PASS: 未対応の効果を捏造せず、UIとログで選択・支払い・条件を確認できる。
5. PASS: 古い保存データを安全に新しい状態へ移行できる。
6. PASS: `npm test`、`npm run lint`、`npm run build` が成功する。
7. PASS: 原作カードの長文テキストや画像を無断転載せず、短い日本語要約と機械処理だけを収録する。
